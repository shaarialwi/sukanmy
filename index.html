Host SukanMY on GitHub Pages

This entire application is engineered as a self-contained single-file web app so you can host it live for free and share the URL with Kementerian Belia dan Sukan (KBS).

  1. 1
    Create a GitHub Repository: Go to github.com/new, name it sukanmy, set to Public, and click Create.
  2. 2
    Upload index.html: Click "uploading an existing file", upload this exact index.html file, and commit changes.
  3. 3
    Enable GitHub Pages: Open repository Settings → Pages, under Branch select main and / (root), then click Save. Your live pitch link will be ready in ~30 seconds!
